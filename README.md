# Kaisheng Zhou

Personal academic website for Kaisheng (Jason) Zhou, Computer Science and Mathematics at Carleton College.

A static HTML, CSS, and JavaScript site hosted on GitHub Pages. No build step is required.

Edit `index.html` for content, `styles.css` for appearance, and `assets/Resume_Jason.pdf` to replace the CV. Changes pushed to `main` publish automatically.

Preview locally with `python -m http.server 4173` and open http://localhost:4173.

Cleo logo follows the owner's supplied reference. Historical Maps image captured from the owner's CGMR plugin.
